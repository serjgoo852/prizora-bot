# PRIZORA Cabinet Demo

Isolated responsive account-cabinet prototype.

- No real Telegram authentication or production database.
- No production contests, payment execution, or bot actions.
- Form submissions update sample state in the browser only.
- Participant, organizer, advertiser, profile, and help views are provided for UI review.
- This folder is intended to be deployed as a separate preview app, never as the bot worker.

Current preview data is fictional.
